# BarberKing - Sistema de Gestión de Barbería

## 🚀 Desplegar en Coolify

1. En Coolify, haz clic en **"Redeploy"**
2. Espera a que se construya (5-10 minutos)
3. ¡Listo! Tu aplicación estará funcionando

No necesitas configurar variables de entorno. La aplicación usa SQLite por defecto.
